Suggested changes

Sidebar
Dark navy sidebar apply
Change from light gray to #0f1b2d — matches PlagPro's trust/academic brand. Much easier to read.
Structured nav sections apply
Group links under "Navigation" and "Quick Actions" headers. Adds visual hierarchy.
User profile footer apply
Show logged-in user's name + current plan at the bottom of the sidebar.
Collapsible sidebar consider
Add a toggle to collapse sidebar to icon-only mode on small screens.
Chat area
Suggestion cards on welcome apply
Replace plain text quick-start buttons with icon cards (Check Plagiarism, Pricing, FAQ). Much more engaging.
Quick reply chips after bot answers apply
Add contextual follow-up chips (e.g. "Compare plans", "Get started") after each relevant response.
Subtle chat background apply
Change white bg to #f7f8fb (very light blue-gray). Visually separates messages from bubbles.
Bot avatar in topbar apply
Add a robot icon avatar + "Online now" status in the chat header instead of just a text name.
Colours & branding
Primary accent: #1E56C8 apply
Use PlagPro's brand blue for send button, active nav, quick reply borders, and suggestion card icons.
Green online status dot keep
The green "System Online" dot is good. Keep it but move it to the topbar next to "Online now" for immediate visibility.
Remove dark mode toggle from sidebar fix
Move the moon/sun toggle to the topbar right corner — it clutters the header in current placement.
Input bar
Pill-shaped input + round send button apply
Replace rectangular input with a rounded pill. Blue circular send button replaces plain text "Send".
Add attachment icon consider
Add a paperclip icon in the input bar for document uploads — relevant since PlagPro checks uploaded files.
